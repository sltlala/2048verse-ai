手机版 (Android 真机自动化): adb + 截图识别 + 复用 ai.js

背景: 手机上是原生 App (Lite2048, Unity 引擎)。Unity 把整个画面渲染在单个
SurfaceView 上, uiautomator 读不到任何格子控件 -> 必须走截图识别。

新增 tools/mobile/:
- shot.js       adb 截图 (处理 exec-out 二进制被 CRLF 破坏的兼容回退)
- calibrate.js  校准: 自动定位棋盘 4x4 网格 + 逐格采样颜色
- board.js      识别模块: 颜色众数 -> 方块数值 (COLOR_MAP 映射表)
- bot-mobile.js 主循环: 截图 -> 识别 -> ai.getBestMove() -> adb input swipe
- mine-palette.js / analyze-palette.js  尝试从 APK 挖调色板 (未成功, 保留备用)

关键实现:
- 大号白字会污染中心采样, 改用"颜色众数"(量化到 8 的倍数), 底色像素远多于笔画
- 遇到 COLOR_MAP 里没有的颜色会暂停并保存该格样本图, 人工确认后补表
- 实测: 校准完美 (内部一致性通过: 同值格子颜色一致), 滑动方向正确 (左滑分数+4),
  自动玩约 0.83 步/秒 (截图 480ms + 识别 58ms + 思考 120ms + 等待 260ms)

已确认的颜色映射: 0/2/4/8/16/32/64/128/256/512
(1024 及以上待游戏中出现后补齐)
